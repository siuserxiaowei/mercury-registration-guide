# 大陆用户 → Wyoming 单成员 LLC → EIN → Mercury 企业户

发布：2026-10-24。资料核验截至：2026-10-23。金额均为美元（USD）；费用、规则与处理进度可能变化，提交前复核所附官方入口。

适用情形：一名居住中国大陆的自然人持有 100% 股权，无 SSN/ITIN；在 Wyoming 新设 LLC；默认按 disregarded entity 处理；实际经营在大陆，暂无美国办公室和雇员；有真实业务及现有或计划中的美国业务联系。美国税务居民、有美国员工、多成员、主动选择公司税制等情形需另行判断。

这是一份准备和提交清单，尚未替你注册、付费或递交。方括号均须换成真实信息。SS-4 的业务示例不代表你的实际业务。

## 先确认的三件事

- [ ] 能用一句话说明卖什么、卖给谁、怎样收费，以及现有或计划中的美国业务。
- [ ] 已理解美国公司有年度维护和税务义务，银行拒绝开户不会自动取消公司。
- [ ] 已确定地址方案：美国合格公司法定地址、真实大陆经营/居住地址，以及可接收 IRS 信函的收信地址各自是什么。

Mercury 的公司法定地址必须符合其美国实体地点要求，不能是 PO Box 或虚拟办公室。实际经营地址可以在中国，但不能用注册代理或收信服务代替。官方没有一概禁止所有注册代理地址作法定地址，也没有保证任意商家赠送地址合格。付款前确认服务商地址属性、允许用途、一般邮件和 IRS 信函扫描范围；遇到不清楚的属性，向 Mercury 核实后再付费，不要虚构美国办公室。

依据：[公司地址](https://support.mercury.com/hc/en-us/articles/28769699533588-Company-address-requirements)、[法定地址](https://support.mercury.com/hc/en-us/articles/28769816280084-Updating-your-company-s-legal-address)、[申请资格](https://support.mercury.com/hc/en-us/articles/28770467511060-Eligibility-and-requirements-for-opening-a-Mercury-account)。

## 第一步：确定名称、代理和公司资料

- [ ] 在[Wyoming 官方检索入口](https://wyobiz.wyo.gov/Business/FilingSearch.aspx)检查名称；准备备选名和 LLC 后缀。公司名称可用性不等于商标许可。
- [ ] 选择 Wyoming 合格注册代理并取得所需同意。可查[官方商业代理名单](https://sos.wyo.gov/Business/Docs/CRA-Roster.pdf)，名单不是州政府推荐。
- [ ] 阅读[代理资格说明](https://sos.wyo.gov/Business/Docs/HowToFindOrBecomeARegisteredAgent.pdf)。你人在大陆，不能仅凭大陆住址充当 Wyoming 州内代理。
- [ ] 准备：英文姓名、真实大陆地址、电话、邮箱、经营内容、唯一成员持股 100%、管理方式，以及允许用于各字段的地址。
- [ ] 如用代办，先拿书面总价，区分政府费、服务费、代理续费、EIN、邮件和其他订阅。

可选报价例子：[Northwest 注册服务](https://www.northwestregisteredagent.com/incorporation-service)当前 $39 ＋州政府费、含首年代理，之后代理 $125/年；[无 SSN 的 EIN 代办](https://www.northwestregisteredagent.com/start-a-business/ein-tax-id)另选 $200。这里仅作预算样例，并非必须购买或银行审批保证。

## 第二步：提交 LLC 成立文件

- [ ] 自办从[州官方注册说明](https://wyobiz.wyo.gov/Business/RegistrationInstr.aspx)进入在线流程，选择 Limited Liability Company；使用代办时由其提交，不要自己重复提交。
- [ ] 核对名称、注册代理、经营/收信地址、组织人和管理信息的真实性。
- [ ] 自行在线提交：政府费 $100，当前支付费 2.4%，合计 $102.40。代办渠道按订单列明金额，不机械额外加同一笔在线支付费。
- [ ] 以 A 开头等触发州网站人工审核的名称，按页面提示走纸件，不能把在线即时成立时间套用到纸件。
- [ ] 保存州备案成立文件、收据、公司编号；核对官方检索状态和全部拼写。
- [ ] 签署并保存单成员 Operating Agreement，记录成员身份、100% 权益、管理权限及出资；内部协议不等于又一次政府注册。
- [ ] 建立文件夹：成立文件、EIN、护照/地址证明、业务合同/订单、股东往来、银行流水、年度申报回执。

官方称符合条件的在线流程完成后即可 active，纸件不超过 15 个工作日；实际按审核状态。[州成立指南](https://sos.wyo.gov/Business/Docs/HowToCreateAWyomingCompany.pdf)

## 第三步：申请 EIN

官方入口：[SS-4 正式表格](https://www.irs.gov/pub/irs-pdf/fss4.pdf)、[逐行说明](https://www.irs.gov/instructions/iss4)、[EIN 总览](https://www.irs.gov/businesses/employer-identification-number)。本次正式表格版本为 12/2025。

- [ ] 公司已经成立，名称和日期以实际文件为准。
- [ ] 核对 SSN/ITIN 状态：没有号码不自动等于不具备取得资格；已有号码要如实填，不借用代办号码。无号码并不意味着必须先买 ITIN 服务才能取 EIN。
- [ ] 按下面示例准备 SS-4，所有个性字段换成真值。
- [ ] 自办时签署并保存，留下可接收回传的传真号；委托时只授权明确的第三方，不把其冒填为实际负责人。
- [ ] 本路线实际主要经营地在中国、无美国主要办公室/agency，从中国发送可按当前规则传真至 **+1 304-707-9471**。若发件服务实际从美国发出，对应号码为 **855-215-1627**；若主要经营地/办公室实际在美国，另按 **855-641-6935** 路由。提交前再核对 IRS 当日说明及传真服务实际发送地。
- [ ] 保存已签表、发送成功凭证和所有回复；不要因为等待而重复申请。
- [ ] 传真之外的备选邮寄地址，在本路线下为 Internal Revenue Service, Attn: EIN International Operation, Cincinnati, OH 45999；只选一种申请方式，不同时重复提交。
- [ ] 保存回传 EIN、后续 CP575；需要时向 IRS 索取 147C，不把普通号码截图自动当成银行认可证明。

当前进度：传真约收到后 8 个工作日处理，纸件收到后 30 天内处理；不含你准备材料、跨境邮件、补件及证明送达时间。[IRS 当前进度](https://www.irs.gov/help/processing-status-for-tax-forms)

两项官网口径细节：IRS 总览虽按境外主要经营地概述国际电话申请，但更新的操作手册将美国成立 LLC 归为 Domestic，并要求国际热线转告其他申请方式，因此本清单采用传真/邮寄，不依赖电话即时发号。IRS 当前亦称传真回传的是含 EIN 的封面，已不再返回标注 EIN 的 SS-4。[IRS 操作手册，21.7.13.3.2.7 与 21.7.13.7.1](https://www.irs.gov/irm/part21/irm_21-007-013r)、[EIN 总览](https://www.irs.gov/businesses/employer-identification-number)

## SS-4 填写示例

另行假设：未选择按 corporation 纳税；未来 12 个月不雇员；日历年度；因成立/出资等应申报交易需要履行 Form 5472 义务。若事实不同，不套用税务分类和雇员项目。

| 行号 | 本路线示例 / 填写依据 |
|---|---|
| 1 | `[州成立文件中的完整公司英文名，含 LLC]` |
| 2 | 无不同商号则留空；有 DBA 才填真实商号 |
| 3 | 若本人为税务信函收件联系人，可填本人完整英文名；不适用则不填 |
| 4a–4b | 真实可收 IRS 信函的地址，含房号、街道、城市、省、邮编及 China；不因有注册代理就默认可收普通 IRS 邮件 |
| 5a–5b | 经营地址与第 4 行不同时填真实经营地址；相同则留空；不能填 PO Box |
| 6 | 真实主要经营地，如 `[区/城市], [省], China`，不要直接填 Wyoming |
| 7a | `[实际负责人的护照英文姓名]`；本例为唯一股东 |
| 7b | 无号码且不具备取得 SSN/ITIN 资格时，按说明填 `foreign` 或 `N/A`；不得编造号码 |
| 8a / 8b / 8c | `Yes` / `1` / `Yes`，最后一项问 LLC 是否在美国成立 |
| 9a | 选 `Other`，填 `Foreign-owned U.S. disregarded entity-Form 5472` |
| 9b | 本例未按 corporation 申请，不适用；不要因中国股东而在成立国家栏填中国 |
| 10 | 本例选 `Other`，填 `Foreign-owned U.S. disregarded entity filing Form 5472`；只选一个理由 |
| 11 | 真实业务开始日期，格式 MM/DD/YYYY；确实自成立日起开始业务才填成立日 |
| 12 | `December`，仅适用于本例日历年度 |
| 13 | 三类预期雇员人数各填 `0`，仅限实际都无雇员 |
| 14 | 无预期雇员时跳过，不为零工资勾选 944 |
| 15 | 本例不支付工资/年金且无须填写预扣代理首次支付日期时填 `N/A`；如承担该项预扣代理义务，按说明填真实首次支付日期 |
| 16 | 按真实业务选项；确为网站开发且无对应类别时，可选 Other，填写自拟的具体服务说明 |
| 17 | 网站开发示例：`Website development and ongoing maintenance for business customers`。若是别的业务，改成实际产品/服务 |
| 18 | 新主体从未取得 EIN 时选 `No`；已申请待处理时不要另发一份重复申请 |
| 第三方授权栏 | 自办留空；委托时填写获授权的具体自然人及联系方式 |
| 签名区 | 实际负责人姓名、职务如 `Sole Member`、真实电话、回传传真、签名和日期；可打印手签后扫描提交 |

第 9a/10 行为本例 5472 申报用途，不把任何单人 LLC 都填成 corporation、美国个人独资或仅银行用途。填写前对照[正式表格](https://www.irs.gov/pub/irs-pdf/fss4.pdf)及[官方说明](https://www.irs.gov/instructions/iss4)。

## 第四步：准备 Mercury 企业户材料

- [ ] 州成立文件和内部股权资料。
- [ ] IRS EIN 证明；本清单采用正式证明到手再申请的顺序。
- [ ] 唯一股东及实际控制人护照、真实大陆住址；本例同一人 100% 持股并管理。
- [ ] 如被要求，提供可核验的地址材料；账单显示姓名/公司名、完整地址，并符合时效。银行/信用卡账单通常看最近 90 天。
- [ ] 写清业务、资金来源和美国业务联系；合同、订单、发票或计划按实际阶段准备。
- [ ] 有网站时核对产品、主体、联系方式及业务描述能对应；未开始营收就如实写 pre-revenue，不编造销售历史。

重要修正：Mercury 当前[主站 FAQ](https://mercury.com/faq)允许 EIN 待批时用完整 SS-4 申请，并要求获批后 90 天内补正式 EIN；[帮助中心文件清单](https://support.mercury.com/hc/en-us/articles/28770957425172-Gathering-your-documents)仍强调 IRS-issued 证明。不要再理解成未获 EIN 时绝对不能提交。例外路线能否受理、功能及补件要求以实际申请审核为准。

## 第五步：填写并提交 Mercury

- [ ] 从[Mercury 官方企业入口](https://mercury.com/business-banking)进入申请，不经陌生代登录链接。
- [ ] 公司类型填真实 LLC，唯一成员持股 100%，本人真实管理身份。
- [ ] 公司法定地址、实际经营地址、本人住宅地址、寄卡地址分别填，不混用。
- [ ] 按下面模板写业务说明；删除方括号与不适用分支，预计流水按真实计划。
- [ ] 完成申请所要求的上传和身份验证，提交后确认 In Review。
- [ ] 查收邮箱和垃圾邮件，按要求补件。官方通常 0–2 个工作日决定，补件可延长；7 个工作日无消息时先检查是否有未回复邮件。
- [ ] 获批后开启双重验证，保存银行文件，按真实业务收付款并按月留存合同、票据和流水。

依据：[审核流程](https://support.mercury.com/hc/en-us/articles/28771494745364-What-happens-after-I-submit-my-Mercury-business-account-application)。美国业务联系在开户后仍可能核验，证据应与交易相符。[美国业务验证](https://support.mercury.com/hc/en-us/articles/53171397356820-Verifying-your-U-S-business-operations)

## 可复制的 Mercury 业务说明模板

以下为自拟结构，非官方过审话术。仅保留真实内容；模板中的预计金额不是推荐填报金额。

```text
[FULL LEGAL COMPANY NAME INCLUDING LLC] is a Wyoming single-member company wholly owned and managed by [FULL LEGAL NAME], who resides in China.

We provide [SPECIFIC PRODUCT OR SERVICE] to [CUSTOMER TYPE] in [ACTUAL OR TARGET MARKETS]. We charge [PRICING MODEL]. Our principal place of business is [CITY, PROVINCE, CHINA], where [ACTUAL WORK PERFORMED].

Our U.S. business connection is [EXISTING U.S. CUSTOMER/PARTNER/SUPPLIER RELATIONSHIP OR A CONCRETE U.S. LAUNCH PLAN]. Our current stage is [PRE-REVENUE / OPERATING]. Available supporting information includes [REAL WEBSITE, PRODUCT DEMO, CONTRACT, ORDER OR OTHER RELEVANT EVIDENCE].

Initial funding will come from [ACTUAL DOCUMENTED SOURCE]. Ongoing receipts are expected from [CUSTOMER PAYMENTS / OTHER ACTUAL BUSINESS SOURCE] through [ACTUAL PAYMENT CHANNELS].

We expect approximately USD [AMOUNT] in monthly incoming payments, [NUMBER] incoming transactions per month, and payments involving [COUNTRIES]. These are [FORECASTS / ESTIMATES BASED ON EXISTING OPERATIONS].

We intend to use Mercury to [ACTUAL BUSINESS PURPOSES], including paying [REAL BUSINESS EXPENSE CATEGORIES].
```

检查：没有客户就写计划；没有收入就写预营收；美国联系不是租一个地址；不要无依据填美国员工、美国办公室、虚假合同或较低风险行业。填写与 SS-4、网站和材料一致。

## 首年、次年完整预算口径

采用连续 12 个月，避免把成立日历年剩余几个月误当成全年。以下假设 2026-10-23 成立：

- 首年：2026-10-23 至 2027-10-22。包括 2026 税年的申报预算，以及 2027-10-01 到期的第一份州年报。
- 次年：2027-10-23 至 2028-10-22。包括第二年代理续费、2027 税年申报预算，以及 2028-10-01 州年报。
- 代理实际续费日按服务开始日；若早于成立日，应把实际现金支出移至对应期间，不能漏算或重复计入。

基础假设：Northwest $39 代办成立、州费按其订单中的 $100 计，含首年代理；州内使用资产不超过 $300,000，因此最低州年报在线 $61.44；每个税务周期按一家公开报价 $599 预算。该税务样例仅限其标准的一位外国所有人/关联方、一份 5472 加 pro forma 1120、当期按时申报或及时延期的范围，不是所有税款和税表全包。[税务报价及范围](https://hiltzikcpa.com/form-5472-filing-service/)

| 项目 | 首年：自行 EIN | 首年：购买 EIN 代办 | 次年：两种路线 |
|---|---:|---:|---:|
| 州成立费，代办订单口径 | 100.00 | 100.00 | 0.00 |
| 成立代办服务 | 39.00 | 39.00 | 0.00 |
| 注册代理 | 0.00（套餐含） | 0.00（套餐含） | 125.00 |
| EIN IRS 政府费 | 0.00 | 0.00 | 0.00（无常规年续费） |
| EIN 代办 | 0.00 | 200.00 | 0.00 |
| 州最低年报，含当前在线支付费 | 61.44 | 61.44 | 61.44 |
| 5472 + pro forma 1120 服务预算样例 | 599.00 | 599.00 | 599.00 |
| Mercury 基础开户/必需月费 | 0.00 | 0.00 | 0.00 |
| 当前适用 BOI 政府申报费用 | 0.00（本路线美国成立实体豁免） | 0.00 | 0.00 |
| **上述基础小计** | **799.44** | **999.44** | **785.44** |

基础两年合计：自行 EIN **$1,584.88**；购买 EIN 代办 **$1,784.88**。以下变量另加，未询价或未判断的项目不默认为零。

报税服务的 $599 是委托报价样例，不是 IRS 强制收取的政府费；如果你自行正确履行申报义务，可替换为实际准备和提交成本，不能据此删除申报事项。

| 变量 | 如何计入首年、次年 |
|---|---|
| P：下单附加费 | 采用服务商真实结账单。不要在 $100 代办州费之外一律再加自行 Wyobiz 才核验的 $2.40，也不要漏商家实际收取的处理费 |
| F：传真/回传/邮寄 | 自行 EIN 按实际服务报价；代办仅在书面范围已包含时不另计；停止不再需要的订阅 |
| A：合格法定地址和收件服务 | 若已有且合格、套餐确实覆盖，可无新增费用；否则先确认地址性质和 IRS 普通信扫描范围，再按书面报价列 A1/A2；不预设必须租美国办公室 |
| D：网站、域名、邮箱和电话 | 按真实业务需求；已有资源可无新增支出，新购按订单及续费计入 D1/D2；不自动购买与本路线无关的美国手机号 |
| B：记账、额外税表和专业服务 | $599 标准范围外，如 1040-NR、多关联方、州税/销售税、中国申报、月度记账、历史补报等，另行确定义务和报价 |
| T：实际应缴税款 | 美国联邦、适用州/地方及中国税务义务按实际事实判断；不能因人在大陆或零营收就预设全部为零 |
| U：交易与运营费用 | 外币、汇出行/中转行、非基础付费银行功能、支付平台、退款、卡片寄送等按实际使用计；不把它们混入免费基础账户承诺 |
| V：停业、注销和异常处理 | 仅发生时计入；不继续经营仍需正式处理注销/结税，不能以不登录银行替代 |

完整公式：首年为所选基础小计 + P1 + F1 + A1 + D1 + B1 + T1 + U1 + V1；次年为 $785.44 + P2 + F2 + A2 + D2 + B2 + T2 + U2 + V2。这是范围完整的预算表，实际全包总额需要上述真值才能确定。

若自己在州官网注册，则替换为 $102.40 成立费，删除 $39 代办费，并另加自己购买的注册代理首年报价 R1；不要同时保留“套餐免费首年代理”。银行初始入金是公司资产，不是开户手续费；股东出资需入账并保留来源凭证。
